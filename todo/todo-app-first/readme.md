# Todo List Application

## Описание задачи

Необходимо реализовать приложение для управления списком задач (todo list) со следующим функционалом:

## Требования к функционалу

1. **Создание новой задачи** - возможность создать новую задачу в списке
2. **Получение информации по задаче** - возможность получить детальную информацию по уже созданной задаче по её идентификатору
3. **Получение всех задач**
4. **Получение списка невыполненных задач** - возможность получить список всех задач, которые еще не выполнены
5. **Отметка задачи как выполненной** - возможность отметить определенную задачу как выполненную
6. **Удаление задачи** - возможность удалить существующую задачу из списка
